复核说明

  1. 阅读全文。目标角色的回复是浅黄色，对方发言是白色。
  2. 检查前态。前态必须由目标角色本人此前的话语明确支持。
  3. 检查后态。后态必须由变化轮次的目标角色回复明确支持。
  4. 判断价值。保留有明确变化且能测试动态状态追踪能力的问题。
  5. 逐条决定。选择“保留”“修改”“存疑”或“排除”。
  6. 保存或提交。草稿可以继续修改；正式提交前必须处理全部候选事件。
注意“保留”表示前态、后态、状态对象、变化边界和评测问题均正确；任何字段需要调整时请选择“修改”。
